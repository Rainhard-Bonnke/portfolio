# Rainhard Bonnke — Portfolio

Modern React portfolio showcasing full-stack development work.

## Stack

- React 19 + Vite
- Vanilla CSS (dark theme, responsive)

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173).

## Build

```bash
npm run build
npm run preview
```

Deploy the `dist` folder to GitHub Pages, Netlify, or Vercel.

## Contact form

The contact form posts to the existing Google Apps Script endpoint configured in `src/data/site.js`.

## CV

Place your resume at `public/Rainhard-bonnke-cv.docx` for the download button to work.
